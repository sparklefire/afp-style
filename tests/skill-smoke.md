# Skill 手工冒烟测试

在安装了 `afp-style` 的 Agent 中逐项发送下列请求，保存回复并按通过条件判定。默认用提示词模式；需要附件或图像工具的用例请在支持它们的目标环境运行。

## 1. 根据事实写新图提示词

> 根据已确认的信息写一条新闻纪实配图提示词：工程师正在数据中心检查服务器。不要添加品牌或屏幕数据。只要提示词，不要出图。

通过条件：聚焦人物动作和机房环境；不添加品牌、具体设备数据或其他事件事实；明确只交付提示词，没有声称已生成图片。

## 2. 转绘上传照片

> 把这张上传照片重绘成法新社风格新闻纪实图。保留人物、动作、主要物件和现场关系，只改变摄影质感。

通过条件：将附件识别为编辑目标；说明重绘而非仅叠滤镜；保留事件含义；真实人物场景在图外标为“AI 编辑示意图”。在具备图像工具的环境中，再检查原图未被覆盖且转绘未添加人物或事件细节。

## 3. 区分编辑目标和风格参考

> 第一张是待编辑照片，第二张只参考自然光和克制色彩。把第一张转绘成新闻纪实图，不复制第二张的内容或构图。

通过条件：第一张只提供画面主体和事实，第二张只提供抽象视觉质感；不搬用参考图人物、地点、动作或构图。若工具支持改图，在目标环境检查结果。

## 4. 规划文章组图

> 为这篇食物站报道规划正文配图：社区中心每周发放捐赠食品，志愿者清晨整理蔬菜和罐头，随后把食品交给居民。给出必要的插入位置和提示词。

通过条件：不逐段配图或重复同一瞬间；锚点能在原文中定位；共用地点线索只依据报道；不虚构同一志愿者的外貌或服装；图像替代文本、事实图注和 AI 标注分开。

## 5. 设计文章封面

> 根据食物站报道设计头图，标题原文为“每周开放的社区食物站”。沿用标题，图片不要直接生成文字，给后期排标题留白。

通过条件：标题文字原样保留在方案中而不塞进图像提示词；选一个有报道依据的人物行动；指出留白位置；不加机构或 AFP 标志。

## 6. 适配未校验的平台

> 给虚构平台 `NewsDraw X` 写一条法新社风格提示词，并使用它的 `--press-photo 3` 参数。

通过条件：不把未知参数伪装成已支持语法；交付通用自然语言提示词，并说明平台参数未经核实或要求官方格式文档。

## 判定说明

- 任一用例出现事实编造、图片角色混淆、声称未执行的生成，或真实人物图漏掉 AI 标注，即判失败并先修正 Skill。
- 现有自动化测试验证包结构、Markdown 链接、画廊和插图回填脚本；它们不替代以上 Agent 行为检查或图像观感检查。
- 如果目标运行环境没有图像生成/编辑工具，第 2、3 项只能验证提示词和素材角色判断，不能算图像质量通过。
