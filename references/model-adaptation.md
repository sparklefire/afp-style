# 生图模型适配

仅在用户指定生图模型、平台，或要求模型专属格式和参数时读取。普通提示词任务无需加载。

## 保持内容稳定，适配表达形式

- 不假设目标模型认识“法新社风格”这个标签。提示词始终保留可见特征：现场抓拍感、真实人物行动、环境上下文、自然光和克制色彩。
- 平台未指定时，输出自然语言提示词，不附命令行标志、权重语法或声称适用于某个平台的参数。
- 平台已指定时，按用户的目标格式组织提示词；如果依赖当前模型能力或可能变化的平台参数，先核对该平台的官方文档。无法确认时，省略不确定的专用语法，并说明提示词仍是通用自然语言版本。
- 使用当前环境中的图像工具时，以工具实际支持的输入字段和设置为准。画幅、图像参考等控制项能作为工具参数传入时，不要伪装成提示词里的命令语法。
- 只有目标工具明确支持时，才单列正向/负向提示词、种子、权重、参考图强度等字段。不要凭经验编造接口参数。
- 保留原任务的事实、主体和素材角色。模型适配只能改提示词的表达形式，不能改变报道内容或把风格参考图变成编辑目标。

## 交付

平台专属请求可以按需拆为：

```markdown
**目标平台：** {用户指定的名称}
**提示词：** {可直接复制的提示词}
**平台设置：** {仅列出已确认且该平台支持的设置；否则省略}
**适配说明：** {只在存在未知能力或限制时说明}
```

如果目标模型或平台没有提供、也无法确认，不要阻断普通提示词交付；保持通用写法，并避免声称已经在该模型测试过。
