# 新闻文章封面

用于从报道、文章或事件说明中设计新闻纪实类封面、头图和社媒横幅。若用户要求多张正文插图，改读 [article-visual-planning.md](article-visual-planning.md)。

## 封面判断

- 先找出文章的核心事件和读者最需要看见的人物行动，不把标题逐字画成场景。
- 一张封面聚焦一个瞬间。用人物和环境交代主题，避免拼贴、概念海报、产品展示和夸张的点击诱导画面。
- 保留自然光、真实环境和克制色彩。版面服务阅读，不要把新闻照片包装成商业广告。
- 有真实标题时按用户原文保留。没有标题时，可提出简短标题备选，但必须能由文章事实支持，并和画面提示词分开。

## 文字与画面

- 默认只生成照片画面，不在图中生成标题或副标题；给后期排版留出干净的文字空间，并说明建议位置。
- 用户明确要求文字直接入图时，只使用其提供或确认的准确文本。不要擅自润色事实性标题、增加机构名称、徽标或 AFP 署名。
- 用户指定渠道、比例或文字位置时按要求组织画面。没有指定时，不添加具体比例，选择适合主体的横向新闻照片构图。
- 文字留白不能遮挡人物动作或关键现场信息。标题较长时建议后期排版，不要压进提示词让模型自行编字。

## 交付格式

```markdown
**封面视角：** {这个瞬间如何呈现报道重点}
**标题：** {用户提供的标题；未提供时给可选文案并注明是建议}
**构图建议：** {主体位置和后期文字留白位置}
**生图提示词：** {可复制的法新社风格新闻纪实提示词}
**发布标注：** {涉及真实事件或人物时填写“AI 生成示意图”；否则省略}
```

涉及真实事件或人物时，在封面图外标注“AI 生成示意图”。只有用户明确要求生成、编辑或预览时才调用图像工具；封面生成结果仍需按 `SKILL.md` 的事实边界检查。
