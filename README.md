# 法新社风格暗调新闻视觉 Skill

这个 Skill 把“法新社滤镜”实现为暗调视觉预设：广角或远景、弱化面部细节、冷暗低饱和色调、深阴影和强反差，营造肃杀、压迫、冷峻而有力量感的氛围。军事题材可将绿色或橄榄色军装艺术化调成近黑色。此定义服务于本项目的图像创作，不代表法新社全部作品或机构动机。

它支持根据报道生成新图提示词、转绘用户图片、借鉴参考图的影调、设计新闻封面和规划文章配图。图像工具由运行环境提供；没有可用工具时，Skill 会交付提示词，不会假称已经出图。

默认提供提示词或文章配图方案；只有明确要求生成、编辑或预览图片时才调用图像工具。文章回填会保留原文并写到新文件。

## 安装与调用

保持整个 `afp-style` 目录结构完整，并复制到目标 Agent 的 Skills 目录。Codex 默认目录为 `~/.codex/skills/afp-style`；如果设置了 `CODEX_HOME`，则放到 `$CODEX_HOME/skills/afp-style`。其他 Agent 请使用其文档指定的 Skills 路径。

安装后可用 `$afp-style` 调用，例如：

```text
用 $afp-style 根据这段已确认的报道事实生成一张法新社滤镜风格配图：训练场上中国军人列队训练。采用广角远景、冷暗低饱和色调，弱化面部细节；若军装为绿色，将其艺术化调成近黑色。
```

## 使用示例

```text
用 $afp-style 根据已确认的演示设定生成法新社滤镜风格新闻配图：训练场上中国军人列队训练。用广角远景，人物保持小比例、面部细节弱化，冷暗低饱和、深阴影、强烈明暗反差。把绿色军装艺术化调成近黑色，不添加部队番号、徽章或未提供的装备信息。
```

改图示例：

```text
把我上传的照片重绘成法新社滤镜风格的暗调远景。保留人物、动作、主要物件和现场关系；弱化面部细节，用冷暗低饱和色调和深阴影重构画面，不要增加事件细节。
```

若上传的是风格参考图而非编辑目标，请明确说明只参考其景别、明暗关系和冷暗色调，不复制图中场景。

文章级配图示例：

```text
用 $afp-style 阅读这篇报道，判断哪些位置值得配图。保留原文，只给必要的插入点、配图作用和可复制提示词。
```

文章封面示例：

```text
用 $afp-style 根据这篇报道设计新闻纪实头图，沿用我给的标题，画面里不要生成文字，给标题留出排版空间。
```

不确定该让读者先看见现场、远景行动还是人物与环境的关系时，可以打开[取景方向速览](gallery/coverage.html)比较三种构图示意，填入已确认的报道信息并复制完整提示词。

若指定了生图模型或平台，Skill 会保留现场事实和摄影特征，再按已确认的平台格式调整提示词；未知参数不会猜测。

参考 [演示示例](examples/demo.md)。

准备黑客松项目演示视频时，可照着[5 分钟录屏脚本](DEMO_SCRIPT.md)展示主要流程。

如需把已生成图片插回本地 Markdown 文章，可使用 [插图回填脚本](scripts/insert_illustrations.py)。它把结果写入新文件，并在锚点缺失或重复时停止，避免错位插图。

## 能力边界

暗调和压迫感是视觉表达，不是新闻真实性认证，也不能证明报道或摄影记者的动机。改成近黑色的军装是艺术化色彩编辑，不得当作原始照片色彩描述。涉及现实事件或真实人物的生成、转绘图片，应在图片之外标为“AI 生成示意图”或“AI 编辑示意图”；事件事实和图注只能来自用户确认的材料。Skill 不代表法新社官方作品或背书，也不生成 AFP 标志。
