# 法新社风格新闻纪实视觉 Skill

这个 Skill 把“法新社风格”作为一种新闻纪实视觉语言：抓拍感、真实环境、人物行动、自然光和克制色彩。它支持从报道主题生成新图、转绘用户上传的图片，以及只借鉴参考图的视觉质感。图片工具由运行环境提供；没有可用工具时，Skill 会交付提示词，不会假称已经出图。

## 使用示例

```text
用 $afp-style 根据这段已确认的报道事实生成新闻纪实配图：工程师正在数据中心检查服务器。让人看清人物动作和机房环境，不要摆拍，也不要增加品牌或屏幕数据。
```

改图示例：

```text
把我上传的照片转绘成法新社风格新闻纪实图。保留人物、动作、主要物件和现场关系，只改变成像质感；把上传的图片当作编辑目标，不要增加事件细节。
```

若上传的是风格参考图而非编辑目标，请明确说明只参考其光线、色彩或镜头感，不复制图中场景。

参考 [演示示例](examples/demo.md)。

## 能力边界

“纪实风格”描述的是视觉语言，不是新闻真实性认证。涉及现实事件或真实人物的生成、转绘图片，应在图片之外标为 AI 示意图；事件事实和图注只能来自用户确认的材料。Skill 不代表法新社官方作品或背书，也不生成 AFP 标志。
