# 法新社风格新闻纪实视觉 Skill

这个 Skill 支持两种任务：根据已确认的报道事实生成法新社风格新图，或将用户提供的现有图片转绘成这种风格。它突出现场动作、环境上下文和人文视角；直接出图或改图时需要运行环境提供图像生成/编辑工具。

## 使用示例

```text
用 $afp-style 为这段报道写一条配图提示词：工程师正在数据中心检查服务器。画面要让人看到人物正在做什么以及机房环境；不要摆拍，不要加机构标志。
```

改图示例：

```text
把我上传的照片转绘成法新社风格新闻纪实图。保留人物身份特征、动作、主要物件和现场关系，只改变成像质感；如果直接生成图片，请标注为 AI 生成示意图。
```

参考 [演示示例](examples/demo.md)。

## 能力边界

“纪实风格”描述的是视觉语言，不是新闻真实性认证。任何模型生成的新闻场景都必须标为示意图；事件事实和图注只能来自用户确认的材料。
