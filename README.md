# 法新社风格新闻纪实视觉 Skill

这个 Skill 把“法新社风格”作为一种新闻纪实视觉语言：抓拍感、真实环境、人物行动、自然光和克制色彩。它支持从报道主题生成新图、转绘用户上传的图片、借鉴参考图的视觉质感、设计新闻封面和规划文章配图。图片工具由运行环境提供；没有可用工具时，Skill 会交付提示词，不会假称已经出图。

默认提供提示词或文章配图方案；只有明确要求生成、编辑或预览图片时才调用图像工具。文章回填会保留原文并写到新文件。

## 安装与调用

保持整个 `afp-style` 目录结构完整，并复制到目标 Agent 的 Skills 目录。Codex 默认目录为 `~/.codex/skills/afp-style`；如果设置了 `CODEX_HOME`，则放到 `$CODEX_HOME/skills/afp-style`。其他 Agent 请使用其文档指定的 Skills 路径。

安装后可用 `$afp-style` 调用，例如：

```text
用 $afp-style 根据这段已确认的报道事实生成一张新闻纪实配图：工程师正在数据中心检查服务器。
```

## 使用示例

```text
用 $afp-style 根据这段已确认的报道事实生成新闻纪实配图：工程师正在数据中心检查服务器。让人看清人物动作和机房环境，不要摆拍，也不要增加品牌或屏幕数据。
```

改图示例：

```text
把我上传的照片从头重绘成法新社风格新闻纪实图，不要只叠加滤镜。保留人物、动作、主要物件和现场关系；把上传图片当作编辑目标，不要增加事件细节。
```

若上传的是风格参考图而非编辑目标，请明确说明只参考其光线、色彩或镜头感，不复制图中场景。

文章级配图示例：

```text
用 $afp-style 阅读这篇报道，判断哪些位置值得配图。保留原文，只给必要的插入点、配图作用和可复制提示词。
```

文章封面示例：

```text
用 $afp-style 根据这篇报道设计新闻纪实头图，沿用我给的标题，画面里不要生成文字，给标题留出排版空间。
```

不确定该让读者先看见现场、人物行动还是关键细节时，可以打开[取景方向速览](gallery/coverage.html)比较三种构图示意，填入已确认的报道信息并复制完整提示词。

若指定了生图模型或平台，Skill 会保留现场事实和摄影特征，再按已确认的平台格式调整提示词；未知参数不会猜测。

参考 [演示示例](examples/demo.md)。

如需把已生成图片插回本地 Markdown 文章，可使用 [插图回填脚本](scripts/insert_illustrations.py)。它把结果写入新文件，并在锚点缺失或重复时停止，避免错位插图。

## 能力边界

“纪实风格”描述的是视觉语言，不是新闻真实性认证。涉及现实事件或真实人物的生成、转绘图片，应在图片之外标为“AI 生成示意图”或“AI 编辑示意图”；事件事实和图注只能来自用户确认的材料。Skill 不代表法新社官方作品或背书，也不生成 AFP 标志。

